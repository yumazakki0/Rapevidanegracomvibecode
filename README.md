# Vozes da Quebrada

Site da exposição “Vozes da Quebrada: o rap como memória, resistência e transformação social”.

## Desenvolvimento

```sh
npm install
npm run dev
```

```` 

O servidor de desenvolvimento atualiza a página automaticamente quando os arquivos são alterados.

## Build

```sh
npm run build
```

Os arquivos prontos para publicação são gerados na pasta `dist/`.
